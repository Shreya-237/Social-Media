# Social Media Web Application

## 📌 About the Project

Social Media is a Django-based web application developed as part of my **CodeAlpha Internship – Task 2**.

The application allows users to create accounts, share posts, interact with other users, and manage their profiles.

## 🚀 Features

- User Registration
- User Login & Logout
- Create Posts
- View Latest Posts
- Like Posts
- Comment on Posts
- Follow / Unfollow Users
- User Profiles
- Responsive and simple user interface

## 🛠️ Technologies Used

- Python
- Django
- HTML
- CSS
- SQLite
- Git & GitHub
